# ZENTRA

A pixel-art story game about the machines NASA left on the Moon and Mars. Made by team NovaDev for the NASA Space Apps Challenge 2026, challenge "Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars".

Open `index.html` through a web server (or the hosted site) to play. Esc pauses.
